# デスクワーク姿勢改善！机と椅子の最適高さシミュレーター

自分の身長を入力するだけで、人間工学（エルゴノミクス）に基づいた最適な「椅子の座面高」「机の天板高」「ディスプレイの推奨位置」をミリ単位で自動計算するツール

## 🌟 主な特徴
- **完全フロントエンド完結**: サーバー不要でブラウザを開くだけで即座に動作。
- **安心・安全**: データはブラウザのローカル環境のみで処理され、外部への通信は行いません。
- **モバイル対応**: スマートフォン・PCのどちらでも直感的に使えるレスポンシブ設計。

## 🚀 使い方
1. リポジトリ内の `index.html` をブラウザで開きます（または GitHub Pages でアクセス: https://kam2525-hub.github.io/ergonomic-desk-setup-calculator/）。
2. 画面の指示に従って操作します。
